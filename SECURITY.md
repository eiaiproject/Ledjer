# Security Policy

## Supported Versions

Currently only the latest production deployment is supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please email **security@ledjer.id**.

Do NOT open a public GitHub issue.

You can expect a response within 48 hours. We will keep you informed of the fix progress and credit you when the fix is deployed.

## Scope

- Authentication bypass
- Data leakage (tenant isolation)
- Injection attacks (SQL, XSS, CSRF)
- Session hijacking
- Insecure direct object references
