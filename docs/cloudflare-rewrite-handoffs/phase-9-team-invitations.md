## Design Decisions

- Invitation accept is authenticated but does not require current organization membership, because invitees may not have an organization yet.
- Invitation tokens are opaque, generated by Worker crypto, and stored only as SHA-256 `token_hash` in D1.
- Raw tokens are returned only in the create/resend response so the UI can show a copyable invitation link.
- Pending invitation list intentionally does not expose raw tokens. To copy a link again, the UI resends/refreshes the invitation and gets a new token.
- Expired, revoked, accepted, reused, missing, and email-mismatched invitations are rejected.
- Accepting an invitation sets `sessions.current_organization_id` to the invited organization.
- Removed members can be reactivated by accepting a later valid invitation.
- Owner role cannot be changed or removed from the team endpoints.
- Role updates use `admin`, `member`, and `viewer`; `owner` is not assignable by invitation or role update.
- Worker permissions are role-derived. The old Supabase granular `update_staff_permissions` RPC was not ported because the Cloudflare target API is `PATCH /api/team/members/:id/role`.
- Email sending has a `TeamInvitationEmailSender` interface and a dev stub only. No production provider is wired yet.

Ran against local Worker dev server on `http://127.0.0.1:5174` because port 5173 was already in use.

- Registered and manually verified owner, invitee, and revoked-invite users in local D1.
- Owner logged in and created an organization.
- `GET /api/team/members` returned only the owner.
- Owner created a `member` invitation.
- D1 stored a 64-character `token_hash` for the invitation.
- Invitee accepted the invitation.
- Invitee current organization switched to the invited organization.
- Reusing the accepted token returned `invitation_not_pending`.
- Invitee as `member` received `permission_denied` for `GET /api/team/members`.
- Owner promoted invitee to `admin`.
- Admin successfully created a `viewer` invitation.
- Owner removed the promoted member.
- Removed user no longer had organization access.
- Owner created and revoked another invitation.
